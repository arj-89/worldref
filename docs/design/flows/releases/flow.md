# Flow: release notes (Stop 1, Delegated mode, lean per entry 25)

- **Job:** a developer checks what changed between the version they use and the newest one.
- **Entry:** the footer link «سجل الإصدارات» / "Release notes", on every page.
- **Page:** title, one-line lead (what the three version numbers mean), a link to the GitHub releases (files), then one section per version, newest first: version as the heading, date, the entry's notes as a list.
- **Sources:** English renders `CHANGELOG.md`; Arabic renders `CHANGELOG.ar.md`, written natively. A version the Arabic file does not cover yet (an automatic data release) shows `releases.auto` and its date, so the Arabic page never shows English prose.
- **States:** static page, no loading or error state; nothing to empty.
- **Primary action:** none needed beyond reading; the GitHub link is the only action.
