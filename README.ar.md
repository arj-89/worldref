# worldref

**جميع دول العالم بالعربية والإنجليزية:** الأسماء والجنسيات والعواصم والعملات واللغات والمناطق الزمنية ورموز الاتصال والتحقق من أرقام الجوال وصيغ العناوين والتقسيمات الإدارية. قاعدة بيانات واحدة جاهزة بصيغ JSON وCSV وSQL، ومكتبات لـ TypeScript وPython وSwift وKotlin وDart وPHP وGo وC#، وخادم MCP لوكلاء الذكاء الاصطناعي.

[English](README.md) · [الموقع والبحث التجريبي](https://arj-89.github.io/worldref)

</div>

```js
import { countries, search, parsePhone, byIso2 } from "worldref";

byIso2("SA").name_ar;                        // "السعودية"
byIso2("SA").nationality.nationality_ar_f;   // "سعودية"
search(countries, "الامارات", "ar")[0].iso2;  // "AE"
parsePhone("٠٥٠١٢٣٤٥٦٧", byIso2("SA"));      // { e164: "+966501234567", valid: true, mobile: true }
```

## لماذا worldref

- **عربية أصيلة لا مترجمة:** الأسماء الشائعة المختصرة (السعودية)، والجنسية بصيغتي المذكر والمؤنث (سعودي / سعودية)، وبحث يتجاهل «ال» والتشكيل والتطويل وأشكال الهمزة، ويقبل الأرقام العربية والفارسية، ومفاتيح ترتيب تعطي الترتيب الأبجدي العربي الصحيح على كل المنصات.
- **لغة واحدة أو لغتان:** كل ملف بثلاث نسخ: ثنائية اللغة (`name_ar` و`name_en`)، وعربية فقط (`name`)، وإنجليزية فقط (`name`).
- **حقل جوال يعمل كما يجب:** رموز الاتصال، والأطوال الصحيحة، وبادئات الجوال، وأنماط تحقق دقيقة لكل دولة، مع حفظ الرقم بالصيغة الدولية.
- **كل ما يحتاجه النموذج أو التطبيق:** الأسماء الرسمية، والعواصم، والعملات ورموزها (ومنها رمز الريال السعودي الجديد)، واللغات الرسمية، وبداية الأسبوع والعطلة، والتقاويم المفضلة (ومنها أم القرى)، وقواعد الرمز البريدي، وصيغ العناوين، وأرقام الطوارئ، وأنواع المقابس والجهد الكهربائي، ورموز فيفا واللجنة الأولمبية، والتقسيمات الإدارية وفق ISO 3166-2.
- **موثّقة لا مُخمّنة:** المصادر الرسمية أولًا، ولكل عمود مصدره في [`data/sources.json`](data/sources.json). القيمة المجهولة `null`، ولا تخمين ولا ترجمة آلية.

## استخدم ما تحتاجه فقط

- البيانات مقسمة إلى وحدات يجمعها المفتاح `iso2`: `core` و`nationality` و`phone` و`currency` و`geo` و`locale` و`address` و`travel` و`sports`، إضافة إلى `subdivisions`.
- لكل وحدة ثلاث نسخ: `.json` (عربي وإنجليزي)، و`.ar.json` (عربي فقط)، و`.en.json` (إنجليزي فقط).
- القيمة `null` تعني أنها غير معروفة، فلا تملأها بتخمين.

## سياسة البيانات

- **إسرائيل غير موجودة في هذه البيانات** بأي اسم أو رمز، في أي ملف، ويتحقق اختبار آلي من ذلك.
- **فلسطين** دولة، عاصمتها «القدس». الأرقام التي تبدأ بـ **+970 و+972** (ومنها القدس وأراضي 48) أرقام فلسطينية. عملاتها الدينار الأردني و«الشيكل».
- **الأماكن المتنازع عليها تتبع المواقف الرسمية للمملكة العربية السعودية:** الصحراء الغربية جزء من المغرب، وكوسوفو مدرجة، وشمال قبرص غير مدرجة، وتايوان وهونغ كونغ ومكاو أقاليم لها جنسية.
- طلبات تغيير هذه السياسة تُغلق دون نقاش. تصحيحات البيانات مرحّب بها مع رابط المصدر (انظر [CONTRIBUTING](CONTRIBUTING.md)).

## الأسئلة الشائعة

**أين أجد قائمة الدول بالعربية؟** في `data/worldref.ar.json`، ورتّبها حسب الحقل `sort`.

**أين أجد قائمة الجنسيات بالعربية مذكرًا ومؤنثًا؟** في `data/modules/nationality.json`: الحقلان `nationality_ar_m` و`nationality_ar_f`.

**كيف أتحقق من رقم جوال سعودي؟** `parsePhone(input, byIso2("SA"))` ثم تحقق من `valid` و`mobile`. تُقبل الأرقام العربية.
